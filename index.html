[02]Sobre mí

Backend sólido, frontend claro y criterio de producto.

Soy Santiago Valenti, desarrollador Full Stack Java con más de 2 años de experiencia diseñando, desarrollando y desplegando aplicaciones web en producción. Me especializo en Spring Boot, Spring Security, APIs RESTful y MySQL, con foco en sistemas reales que necesitan backend sólido, interfaces claras, integraciones y despliegues confiables.

Tengo experiencia en arquitectura de microservicios, contenerización con Docker y despliegue en VPS Linux. Trabajé en sistemas con más de 800 usuarios activos y volúmenes superiores a $10.000.000 ARS mensuales, integrando Mercado Pago, OAuth2 y flujos con manejo de concurrencia.

También uso AI Agents como GitHub Copilot y Codex como asistencia de desarrollo, siempre supervisando, corrigiendo y validando el código generado para mantener calidad, seguridad y criterio técnico.
